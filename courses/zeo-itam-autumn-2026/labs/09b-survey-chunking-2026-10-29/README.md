# Survey chunking lab: historical October 29 handouts

These student and instructor notebooks preserve the last self-contained survey lab handouts from October 29, 2026. They teach how page boundaries, questions, and chunking choices affect retrieval from fictional survey responses. Open `survey-lab.ipynb` for exercises; `survey-lab-instructor.ipynb` contains reference answers.

This recovery does not certify a fresh Colab run or make these notebooks a current course assignment. The notebooks have no saved execution outputs. Installing libraries, downloading optional models, and running OCR require a suitable runtime; review the setup cell before running it. The fictional survey and drawn handwriting are teaching inputs, not observed customer data. The optional real-handwriting path is separate.

Caveat and Reenie Beanie font data are embedded in the notebooks. Their SIL Open Font License notices are in `licenses/`.

The handout bytes are preserved unchanged. Historical class observations are not results from a new run.
