# 09 · Document processing: where did Lucy's phone number disappear? (class notebook, 27 October 2026)

The notebook for the ITAM class of 27 October 2026. It follows one made-up delivery note through a document pipeline, from the page to the field an assistant would use. Run the cells in order. Every result is labeled LIVE (computed by the cell) or RECORDED (read from a saved earlier run).

## Open it in Colab

The Colab link is added here when this folder is merged, pinned to the merge commit.

## What is in this folder

- `itam_1027_document_processing_lab.ipynb`: the notebook. Its first cell installs the pinned packages (several minutes) and downloads the inputs below.
- `bundle/`: the inputs the notebook downloads, with a `MANIFEST.json` of SHA-256 hashes. The notebook checks every file against it.

The delivery notes, the phone number "55 0100" and the companies are made up for the class. Two cells that call a hosted model replay saved answers, because they need keys that students do not have.
